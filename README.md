## EnsembleMCMC.jl

A simple, low-level differential evolution-based MCMC sampler. Designed to run likelihood evaluations in parallel for compute-heavy forward models. Derived from [ter Braak, 2006](doi.org/10.1007/s11222-006-8769-1) with additions and modifications from Jason Vrugt's [DREAM](https://www.pc-progress.com/en/onlinehelp/dream1/manuals/DREAM_TechManual.pdf).
